# web-iaw

Web sencilla para practicar Git y GitHub en el módulo de Implantación de Aplicaciones Web (2º ASIR).

## Descripción

Tiene una página principal (`index.html`), una página de contacto (`contacto.html`) y una hoja de estilos (`estilos.css`).

## Requisitos

Solo hace falta un navegador web.

## Instalación

```
git clone https://github.com/rubenerenassoto-ux/web-iaw.git
```

## Ejecución

Abrir `index.html` con el navegador.
